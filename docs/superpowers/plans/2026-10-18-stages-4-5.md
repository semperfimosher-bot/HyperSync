## Implemented changes and review rulings

- Deferred all nine page modules under Suspense inside the existing error and
  Activity boundaries. The audio player remains in the persistent shell.
- Entry script 535.88 kB -> 326.79 kB (about 39% smaller). Initial HTML scripts
  total 360,400bytes; `npm run build` enforces <400,000bytes and checks every
  inventoried module/CSS asset exists with matching HTML/worker identity. These
  are payload bounds, not a claimed navigation-latency measurement.
- Admin files/folders/upload list render 100rows per page, retaining aggregate
  counts, artist-folder selection, bulk actions and access to all rows. Global
  and hidden catalog references are cleared after the last subscriber leaves.
  Generation fences suppress stale async state; mutation recovery does not
  repopulate an unused store. A page selection survives reload of released data.
- Artwork uses bounded stream reads at the existing 12MiB ceiling and async image
  decoding. Missing/false headers cannot cause whole-response accumulation.
- Generated build cache holds all 44code/CSS assets, including deferred pages.
  Four downloads at once; 10-second resource/document deadline; 1MiB HTML bound.
  Navigation's 3.5-second deadline now includes preload and HTML body reads.
- Install/preparation cannot publish mixed-build or incomplete HTML. Failed
  installation removes its partial cache. One prior complete activated build is
  retained, with hashed-asset fallback for open tabs.
- Review ruling: cache creation order is insufficient after rollback. Persist
  activation order instead; A -> B -> rollback A -> C retains A, not B. Regression
  covers this ordering; browser scenario exercises actual worker rollback.
- Review finding fixed: initial HTML headers/body also need deadlines. Both
  stalled-header and stalled-body regressions pass, including aborting body reads.
- Forced IndexedDB closure now invalidates cached handles; reopen preserves
  media/artwork bytes. Existing schema/version and ownership policies remain.
- Review validation gaps addressed: browser tests now attempt a genuinely new
  worker whose installation fails, wait for redundant state, and verify incumbent
  controller/offline HTML. Real stalled preload is exercised. Actual application
  player is restored from persisted metadata and played via its UI while
  navigating lazily; native Audio is observed, not replaced with a stand-in.
